Brain API key

Keys are sent only to this workspace server and the selected provider. They are never saved to disk or browser storage by this app. Use HTTPS when deployed.

One optional Brain is BYOK-only. Your two workers are local.
Planning and combined reports use only your session key, never a server key. Your provider bills your usage; an existing chatbot subscription usually does not include API credits.

Connection status means a key is present, not that it has been verified.

Saved runs

Saved on the computer running Relay, up to 100 recent runs. No API keys or PDF files are saved. Tasks, assignments and outputs may contain sensitive information. Delete a run to remove its history record. Pending plans cannot be resumed after restart.

A real MCP connection to an isolated server folder. No access to your computer, shell commands or desktop apps. Tools run only when you click; models cannot invoke them yet.

Connect models on your PC
First runtime supported: Ollama. Other local runtimes are not supported yet. Install Node.js 22+ and Ollama, then download/extract this project on the same PC.
1. Start Ollama
If the Ollama desktop app is already running, skip this command. Otherwise use a separate terminal:
ollama serve
2. Check your downloaded models
ollama list
If you need two models, these are optional examples. Downloads use disk space and running them needs sufficient RAM/VRAM:
ollama pull llama3.2:3b
ollama pull qwen2.5:3b
3. Start Relay in the extracted project folder
npm ci
npm run local
Open http://127.0.0.1:3000, click Refresh models, then select a model in each slot. Keep the terminal open. Ctrl+C stops Relay. You do not need to expose Ollama to the internet or change its CORS settings.
This hosted preview cannot connect to your PC. A terminal command here runs on the server, not your computer. This release is a local browser app, not a signed desktop installer.
Compare mode needs no cloud API key. For Brain mode, enter one provider key in Brain API key settings. PDF text and task context are sent to that provider for planning and synthesis.


Runtime diagnostics
These are resources of the computer running Relay—not necessarily this browser’s PC. The hosted preview reports sandbox resources. This check does not run a model or call a cloud provider.
No hostname, user directory, API key, task text or PDF content is collected. GPU/VRAM and actual model fit are not measured. Context estimation is not an exact tokenizer.
